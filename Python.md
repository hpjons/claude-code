## Hvað er Python?

Python er túlkað, æðra forritunarmál (high-level language) og sérstaklega þekkt fyrir læsileika og einfaldleika miðað við mörg önnur forritunarmál. Python er gríðarlega vinsælt forritunarmál ekki síst vegna þess hversu sveigjnlegt það er og allra þeirra skráarsafna sem það getur notað og búið er að þróa í kringum það. Hugbúnaðarhönnuðir um heim allan nota Python til ýmissa verka eins og í vefforritun, gervigreind, vísindalegri forritun, gagnavísindum o.fl. Python er einnig vel nýtilegt sem reiknivél og hjálpartæki við ýmis verkefni í námi. Python er svokallað hlutbundið forritunarmál.

### Af hverju Python?

* Auðvelt að læra: Einföld málfræði og læsileiki gera Python sérlega heppilegt fyrir byrjendur í forritun.

* Sveigjanleiki: Notað mjög víða við ýmis verkefni

* Samfélag og leiðbeiningar: Mjög stórt samfélag er til í kringum Python á vefnum og mikið til af hjálpargögnum og leiðbeiningum.
